# 地质勘测野外工作站简易操作台勘测小队绑定台账系统

## 项目简介

本系统用于地质勘测后勤管理，实现野外操作台与勘测小队的绑定台账管理，支持按小队分组归集资产和按队员维度关联查询。

## 技术栈

- **前端**: Vue3 + Vite + Element Plus + TypeScript
- **后端**: Spring Boot 3.3 + JDK 17 + JPA
- **数据库**: MySQL 8.0 + Redis 7
- **容器化**: Docker + Docker Compose

## 访问地址

- 前端: http://localhost:8128
- 后端API: http://localhost:8138
- MySQL: 127.0.0.1:3354
- Redis: 127.0.0.1:6427

## 核心功能

1. **野外操作台基础档案录入** - 编号、承重、适配野外工作站
2. **勘测小队初始归属绑定** - 分配操作台所属外勤小队
3. **小队归属调整登记** - 更换操作台归属小队，留存变更记录
4. **按队员编号查询所属小队全部操作台** - 队员维度关联查询资产
5. **小队资产归集总览** - 按小队统计操作台数量和总承重
6. **岩心样品袋送检登记台账** - 每支小队登记送进站的样品袋：袋号、所属小队、送检队员、袋重、送检日、在途/办结状态

## 岩心样品袋送检台账规则

- 每条登记记录：**袋号、所属小队、送检队员、袋重(kg)、送检日、状态（在途/办结）**。
- **同一小队、同一送检日、同一袋号只能落一条**：数据库唯一索引 `uk_sample_bag_team_date_bagno` 兜底，应用层先查重。
- **两人几乎同时交同一袋**：登记时先对所属小队行加悲观写锁，把同小队的并发送检串行化，「查重 + 落账」原子执行——先到的一条进账，后到的失败，并明确提示是哪只袋已在途/办结。
- **绝不自动作废旧袋、绝不允许悄悄改袋号/送检日后顶替**：重复袋号本次登记直接失败；修改时若改后与同队同日另一条撞号同样失败。
- **办结（出站）袋冻结**：在途袋可「出站办结」；办结后不能直接改小队或袋重（也不能改袋号/送检日），必须先「退回在途」再改。对办结袋直接改小队本身即失败，不会留下办结后还被挪队的记录。
- 状态流转：在途 `1` ⇄ 办结 `2`（办结可退回在途）。
- **小队资产总览**与**按队员查询所属小队**均额外展示：**在途样品袋数、在途袋重合计(kg)**（仅统计状态为在途的袋子，办结不计入）。
- 送检队员必须属于所选小队且在职，否则不能由该小队送检。

## 随队总承重上限规则

- 每支小队在档案中核定**随队总承重上限(kg)**，只能在小队档案（新增/编辑小队）中单独修改。
- 新建操作台指定归属小队、或将已有操作台改挂/转移到另一支小队时，按「该小队已挂在用台承重合计 + 本台承重」对照上限校验：**超出即失败**，明确提示超出多少，操作台仍留在原小队（无原小队则保持未挂靠），不会自动挪走其他台、也不会自动放宽上限。
- 并发挂靠同一小队时按小队行级悲观锁串行校验落账，先完成的成功，后提交的若超限必须失败，已用承重不会超过上限。
- 把上限改小到低于该队当前在用台承重合计时，本次修改整体失败，不会留下账面超限的小队。
- 已停用操作台不计入已用承重和总览台数；停用期间仍记在原小队名下，不能改挂到其他小队，需先「恢复在用」（恢复时同样校验上限）再走改挂。
- 小队资产总览与按队员查询所属小队资产时，均展示**承重上限、已用承重、剩余承重**。

## 队员停用（离队）规则

- 停用即离队：只把队员置为 `status=0`，保留原小队关联作为历史归属，但**不再计入任何在职口径**。
- **按队员编号查询所属小队资产**：
  - 编号根本不存在 → 报「队员不存在」；
  - 编号存在但已停用 → 明确返回 409「该队员已停用离队，不再属于任何在职小队，不能查询其原小队操作台、承重等资产清单」，**不吐出原小队操作台、承重、在途袋等任何资产数据**（不是只灰列表，也不是只加一句话却仍返回资产）。
- **停用后不能改挂到任何小队，也不能编辑档案**（姓名/电话/职位/编号均冻结）：编辑、改挂一律 409 失败。不做自动恢复在职，也不允许靠悄悄改队员编号让改挂蒙混过关；确需重新派驻须按重新入职建档处理（新编号不得与含离队者在内的在库编号重复）。
- **不再作为在职队员出现在小队档案里**：小队花名册、按小队查队员只返回 `status=1`；小队资产总览新增**在职队员数**，停用即从人数中剔除。
- **并发兜底**：改挂/停用先对队员行加悲观写锁并在锁内复查 `status`。两人几乎同时把同一名停用队员改挂到两支不同小队时，两笔请求都看到已离队、**两边都失败**，不会留下停用后还被两队同时认领的记录。
- 停用队员同样不能作为送检队员登记样品袋。

## 启动方式

### 方式一：Docker Compose（推荐）

```bash
docker compose up -d --build
```

### 方式二：本地开发

**后端**:
```bash
cd backend
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
mvn spring-boot:run
```

**前端**:
```bash
cd frontend
npm ci
npm run dev
```
